# Nisha Trends - Trendy Clothes Store

A responsive, static fashion-storefront built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. There are no build steps or runtime dependencies.

## Deploy to Vercel

1. Import this repository in Vercel.
2. Set the project root to the folder containing this README and `index.html`.
3. Select **Other** as the framework preset.
4. Leave the build command and output directory empty, then deploy.

Vercel serves the static HTML pages and assets directly.
